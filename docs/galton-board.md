# Galton board scene: rules, metadata, checks

Scene file: `scenes/galton.py`. Added without changing any existing file.

## Hard rules (naming, copyright, platform)

1. **Never use the word "Plinko"** anywhere: title, description, tags, hashtags,
   file names, on-screen text, thumbnail. It is a registered trademark of
   FremantleMedia (The Price Is Right) (checked 2026-10-04 on Justia's trademark
   listing; it is not a legal opinion). Use **Galton board** or **bean machine**.
2. **No money, prizes, multipliers, "win" language or casino styling.** Plinko-style
   games are a gambling category; keep this purely a statistics demo.
3. **Audio is synthesized only**: marimba voice, pentatonic scale, pitch = landing
   bin. Do NOT add `--melody` or sample voices to this scene. The melody bank is
   public domain on paper, but famous tunes can still collect Content ID claims
   (for example the Tetris folk tune), and a scale has nothing to match.
4. **YouTube "inauthentic content" (July 2025 rename of "repetitious content")**
   targets mass-produced, templated, repetitive videos and is judged at CHANNEL
   level. A new seed alone is not a new video. Every upload must change something
   a viewer can name. Knobs built in: `--rows`, `--bias`, `--dur`, `--rule`.
   Ideas: 6 rows vs 18 rows; a biased board (`--bias 0.7`) that skews the curve;
   a "what if the middle peg is removed" variant (needs a small code change).
5. Fonts: the engine draws text with "Arial" via cairo (falls back on Linux). Low
   risk for rendered text, but if you want zero doubt, switch `_font` in
   `lib/studio.py` to an open font such as Liberation Sans or Inter (OFL).

## Upload metadata template (no trademarks)

- Title: `Watching 200 balls build a bell curve (Galton board)`
- Description: one honest sentence on what is happening (each ball goes left or
  right at every peg; the pile approaches the normal curve), then your channel
  links. State that the video is generated by code.
- Tags: galton board, bean machine, bell curve, normal distribution, probability,
  satisfying simulation. No "plinko".

## Commands

```powershell
./run.ps1 -Scene galton -Fast -Still -Frame 600          # preview a frame
./run.ps1 -Scene galton -Fast -SceneArgs @('--rule','Every ball goes left or right, at random')
./run.ps1 -Scene galton -SceneArgs @('--seed','2','--rows','10','--label','r10')
python tools/flash_check.py output/galton_*.mp4
python tools/check_clip.py output/galton_*.mp4
```

## What was verified (sandbox, half resolution, vertical, seed 0)

- First and last frame are pixel-identical (loop seam closes; pile drains to empty).
- Audio: about -14 LUFS, peak -6.7 dBFS, silent tail; no clipping.
- `flash_check`: 0 flashes. `check_clip`: ran clean.
- Drop rate climbs: events per 5 s of the main phase went 7, 34, 68 at `--dur 18`.
