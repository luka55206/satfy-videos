Lessons: (1) pi_blocks3's count-driven time mapping works to 3.1 M collisions; `hit_video_times` must be cached (it ran per frame). (2) A baked two-line caption collides with the stickman headers (y 0.205 h): use a single line there. (3) Fine line art (times_circle) raises the encoded seam delta to ~1.0 even when frame 0 == last frame; hold the final state a few frames so the motion is exactly stopped. (4) PowerShell `-replace` with '\n' in single quotes writes a literal backslash-n: use the Edit tool for multi-line edits. (5) Honest counts: bangs = floor(π/θ) for non-integer π/θ.
